# coffee

# 杯记 · 咖啡萃取日志

个人使用的手机网页，适用于 Sage SES876、自带磨豆机、IMS 54mm H24 粉碗。记录浅烘 SOE 的萃取与冰美式口感，通过可解释的规则生成下一杯单变量调整建议。

## 运行

需要 Node.js 20 或以上，没有第三方运行依赖，无需安装包或配置密钥。

```sh
cd /workspace/coffee
npm start
```

默认端口 3000，可通过 `PORT` 修改。服务启动后访问网页。云环境端口是否可访问取决于平台提供的访问方式。

```sh
npm test
```

## 使用

- 页面分为“记录一杯”“历史记录”“下一杯建议”。切换页面保留未保存的表单输入；保存成功后自动进入建议页。
- 记录页默认展示核心参数与口感，水温／水冰配比以及补充观察按需展开。已填写的折叠字段会一并保存。
- 历史记录默认展示配方与风味摘要，展开后可查看完整信息、编辑、沿用或查看建议。
- 默认包含 7 条历史实验，归为“历史豆批次，信息待补”。第 6 杯为最佳候选；未知时间、日期、水冰配比和评分保持为空。历史默认水温保留为“约93°C”，并非已核实温度。
- 新豆子建立独立批次。时间从启动萃取计时；口感评价以成品冰美式为准，记录加水、冰量及融化状态。
- “沿用参数”会关联对照杯，保存时显示变化及变好／变差反馈。“编辑”更新现有记录。
- 数据仅保存在当前浏览器当前站点的 localStorage，不跨设备同步。清除站点数据会丢失记录，建议定期导出 JSON 备份。
- 导入会在校验并确认后替换当前记录，不自动合并；请先导出备份。用户文本以纯文本显示。
- 规则不测量萃取率，也不保证诊断正确。喷溅优先检查均匀性，冰美式偏淡先验证稀释，多参数同时变化会提示因果不确定。水温记录为机器档位；第一版尚未根据历史学习温度调整。

## 文件

`src/model.js`：历史数据、校验、对比与建议；`src/app.js`：页面和存储；`src/style.css`：响应式样式；`server.js`：仅提供应用静态文件。
